# English quality demo review

## Comparison source

The directly evidenced English reference is **KooBits Spelling Bits**, a public product demo listed in `koobits-curriculum-video-report.html`:

- Video title: `KooBits Spelling Bits`
- YouTube: https://www.youtube.com/watch?v=CKSaEY7nYLY
- Evidence status: `public_verified`
- Report note: `Not a lesson`

The report contains no public KooBits English curriculum lesson. This project therefore compares interaction grammar—not proprietary lesson content. It borrows the evidenced spelling-practice form: one word problem at a time, manipulable letter units, immediate visual feedback, and a learner turn. The silent-e topic and all lesson copy are original.

## Learning target

Learners explain that a final silent `e` can change a short vowel to its long sound, then apply the pattern to `cap → cape`, `kit → kite`, and `hop → hope`.

## Quality intent

- Language occupies the frame; there is no unrelated B-roll.
- Letters are deterministic HTML text, never generated imagery.
- Sound, spelling, and meaning are revealed in narration order.
- The independent `hop → hope` response window holds for ten seconds before feedback.
- Captions use large two-line-safe typography.
