# Science Quality Demo Specification

- **Objective:** classify a robot as non-living using multiple life-process observations rather than movement alone.
- **Audience:** ages 7–10.
- **Output:** 1920×1080, 30 fps, exactly 160 seconds / 4,800 frames.
- **Learning loop:** phenomenon → prediction → evidence criteria → worked comparison → misconception repair → guided seed example → independent bicycle transfer → recap.
- **Science boundary:** the lesson uses age-appropriate observable life processes. It does not claim that movement is required for life, that every response proves life, or that electricity alone makes something non-living.
- **Interaction:** prediction holds seven seconds; guided response holds six seconds; independent response holds eight seconds. No answer cue appears before each window closes.
- **Visual rule:** every animation represents motion under investigation, evidence appearing, a comparison, or feedback. There are no decorative loops.
- **Accessibility:** captions, 31 px minimum caption type, high contrast, no color-only answer coding, and a static-frame-compatible reduced-motion interpretation.
- **Audio:** locally synthesized narration, restrained local music, and sparse locally generated sound effects; no network media.
